# Code of Conduct

We want this project to be a respectful, useful place for people with different backgrounds and experience levels. Participate with patience, assume good intent where reasonable, and focus feedback on the work.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, threats, and publishing another person's private information. Do not use this project's issues or discussions to share private store data, credentials, customer information, or media you do not have permission to redistribute.

Maintainers may edit or remove content and restrict participation when needed to protect contributors and the project. To report a concern, contact the maintainers using the contact options on the GitHub profile. If no private contact option is available, open an issue titled **Private conduct report needed** without including the sensitive details; a maintainer can arrange a private channel.
