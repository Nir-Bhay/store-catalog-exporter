# Changelog

## 0.1.0 — initial alpha

- Public Shopify catalog pagination, media enrichment and collection relationships.
- Public JSON-LD Product/Offer extraction with bounded sitemap discovery.
- Configurable review CSV fields and explicit vendor override.
- Canonical JSON, image/video manifests, coverage reports and draft Shopify CSV.
- Offline snapshot conversion and local bundle/CSV consistency validation.
- Bounded HTTP retries, robots checks, request pacing, cache and resume.
- Optional public image/MP4 archive and ZIP bundle.
- Synthetic regression tests, developer/agent runbooks and repository privacy checks.

No destination Admin API import, theme migration, browser rendering or universal site parser is included.
